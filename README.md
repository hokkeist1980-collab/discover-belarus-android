# DISCOVER BELARUS — Android MVP\n\nПервая рабочая версия приложения для путешествий по Беларуси.\n\n## Реализовано\n- Главная страница и навигация по пяти разделам.\n- Каталог мест, поиск и фильтры.\n- Карточки достопримечательностей.\n- Избранное (пока в памяти приложения).\n- Демонстрационный маршрут «Минск — Мир — Несвиж».\n\n## Сборка APK\nGitHub Actions запускается при каждом push в main и вручную через Actions → Android APK → Run workflow. APK сохраняется в Artifacts как `discover-belarus-debug-apk`. Это debug APK для тестирования, не релизная подписанная сборка.\n\n## Запуск локально\n`npm install` → `npx expo start`.\n\nПакет Android: `by.discoverbelarus.app`.
